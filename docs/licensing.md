# Free calculations. Optional Notes.

Understand the one-time Notes upgrade, start a trial, and import an issued offline activation file.

<a id="price"></a>

## One-time Notes upgrade

Scientific calculations, variables and functions, graphs, history, and calculator exports stay free. Notes costs $19.00 USD as a one-time upgrade, with a 30-day trial.

> Online checkout through Lemon Squeezy is coming soon. Checkout is separate from using the app offline; no Calcite account or hosted sync service is required.

<a id="trial"></a>

## Start the trial when you are ready

Choosing a library location does not start a trial.

1. Open Settings → License.
2. Choose Start 30-day Notes trial.
3. Open Notes to create, edit, attach files, and explore the library features.

<a id="activate"></a>

## Import an issued offline activation

Once you have an activation file or activation text, it can be applied without contacting a Calcite server.

1. Open Settings → License and expand Activate Notes.
2. Choose Import offline activation and select the issued .cqs-license, .license, or .txt file. Alternatively, paste its text into Activation key and choose Apply offline activation.
3. Check the displayed status and license details. If validation fails, use the original issued file; editing its contents invalidates its signature.
4. Keep the activation file recoverable separately. Opening a synchronized library does not transfer activation to another computer.

> Use activation according to its issued terms. License settings can show one active machine; synchronizing Notes does not grant extra licensed machines.

<a id="open-license-settings"></a>

## Open License settings from the activation page

When the activation page says Your activation is ready, choose Copy activation or Download license file, then choose Open license settings. Your browser may ask you to allow CalciteQuickSolve to open.

1. Open license settings launches the app only when you click it. It opens Settings → License and does not activate a license by itself.
2. Paste the copied activation and choose Apply offline activation, or choose Import offline activation and select your downloaded file.
3. If the app doesn’t open, launch CalciteQuickSolve and go to Settings → License. The page keeps its copy button, download link and manual instructions available.

```
calcitequicksolve://settings/license
```

> The link contains no purchase key, activation token or customer details. Browsers cannot reliably tell whether the app is installed. Launch a standalone download once to complete first-start setup; existing users can enable or repair links under Settings → General → Desktop. If your build is older or registration is missing, the manual activation steps remain available.

<a id="limits"></a>

## Read temporary access and release limits

Special activations, including extended trials, can carry optional limits. Check the values shown in License settings.

| Limit | Meaning |
| --- | --- |
| Usage expires (UTC) | Ends temporary Notes editing access at the specified time, assessed on process startup or an explicit licensing change. An open editing session is not interrupted by expiry. |
| Releases through | Inclusive release-date coverage. A covered release does not stop working merely because a later release exists. |
| Maximum app version | Inclusive app-version ceiling. A newer version outside that limit is not covered. |
| No limit / Never | The corresponding limit is absent. All limits that are present apply together. |

> A temporary activation is different from the advertised one-time Notes upgrade. New CQS4 activation files require the updated app; existing CQS3 files remain supported.

<a id="expired"></a>

## After trial or temporary access ends

The calculator stays free. Previously enabled Notes remains available for reading, copying, export, backup, and recovery, while creation and editing are disabled.

1. Export or back up saved notes when needed; expiry does not delete them.
2. If you receive a renewed or extended activation, import the replacement in Settings → License to restore editing when it is valid.
3. For a release/version coverage mismatch, check the issued terms and use a covered app version or an appropriate replacement activation.
