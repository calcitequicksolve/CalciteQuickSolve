# CalciteQuickSolve 1.0.0

The production release for Windows x64 and Android 11+ ARM64. Download the
installer, standalone EXE or signed APK below. Previous versions have been
withdrawn from public download.

- Scientific and programmer calculations, reusable functions and variables,
  2D/3D graphs, and Markdown notes with attachments, encryption and QR transfers.
- Immutable, hash-verified history preserves offline branches, attachment data
  and resolutions. Git-style ancestry works without a synchronized `.git` folder.
- Complete incoming updates and compatible concurrent edits merge automatically.
  Open notes refresh while preserving typing, cursor position and selection when
  possible; CQS explains when a conflict or changed text needs attention.
- Conflict review shows bordered excerpts and Basic/Advanced choices. A count
  notification and `!` in History/Search open review. Resolve once and the
  resolution propagates to other devices, including after restart or unlock.
- Choose automatic merges, review every incoming change, or use the local/received
  version with a notification. Both histories remain available. Encryption changes
  and deletion/edit conflicts require the configured protection/content decision.
- Tab inserts a literal tab; Shift+Tab removes an adjacent tab. Ctrl+Tab and
  Ctrl+Shift+Tab move focus. Notes settings can disable tab insertion.
- Refresh History after syncing, choose a new note’s workspace before first save,
  and reinitialise or reconnect unavailable workspace folders with confirmation.
- Android has compact controls, guarded workspace removal and retained-folder
  imports. Unsupported live disk exports stay hidden.
- Windows checks the public GitHub repository for production updates by default;
  beta updates remain opt-in. Website downloads also link directly to GitHub.
- Website, public repository and offline Help share the updated workflow guides.

Keep Syncthing conflict copies enabled. `maxConflicts=0` removes a recovery layer;
it is not required for CQS merging. Ordinary file conflicts do not stop Syncthing.
CQS validates and captures recognized copies, archives them locally and publishes
the resolved note and history. Provider permission, disk-space, missing-folder or
filename-case problems still need attention in that provider.

Windows executables are Authenticode unsigned; the installer has the CQS updater
signature. SHA-256 checksums identify the exact published downloads.

The signed Android APK keeps the original application ID and signing certificate.
Install it over the earlier APK to retain notes, settings, workspace connections
and local vault keys. Do not uninstall the existing app. The corrected package
uses optimized, non-debuggable release code and updates 0.1.8 in place.
This release does not publish an app to Google Play.
