# CalciteQuickSolve 1.0.3 Beta

- The refresh arrows meet the curves on Windows, Android and the Web UI.
- Set `license.file` in the server JSON5 configuration to use a mounted
  Full/Notes activation. The file can contain line breaks and spaces.
  Settings displays the file path and status. Servers without a valid file
  offer calculator mode.
- Configure `publicAliases` for internal and external HTTPS access to the
  same instance. Register each browser origin’s OAuth callback.
- Review requesting clients in **Settings → API → Workspace approvals**.
  Rejecting a request asks the client to retry. After approval, each device
  starts its first sync.
- Peer links support custom request headers and native OAuth during pairing.
  API settings include a server information table and clone cursor help.
  Externally managed listener fields are read-only.

The Linux amd64 image is `slyke/calcitequicksolve-server:v1.0.3` and
`slyke/calcitequicksolve-server:beta`.
[Server setup and Kubernetes license Secret](https://github.com/calcitequicksolve/CalciteQuickSolve/tree/v1.0.3/docs/hosted-server)

The Windows installer carries the CQS updater signature. The Android 11+
ARM64 APK uses the existing application ID and signing certificate.
