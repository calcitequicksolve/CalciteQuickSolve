# CalciteQuickSolve 1.0.2 Beta

- The hosted Web UI combines notes from active workspaces. Use `/calc`,
  `/notes`, and `/settings/api` to link directly to those views.
- Activate each server with a signed Full/Notes license. Enter it in the Web UI
  or provide it through the container environment or a mounted secret.
- The API settings manage two-way sync credentials, incoming workspace
  approvals, and direct server peers. MCP has its own agent settings.
- Choose workspaces per server. Once a server approves an incoming workspace,
  start its first sync on each device. Server peers can mirror approved
  workspaces over multiple links and catch up after a disconnect.
- Import an individual CQS note by QR in the browser. Windows, Android and the
  browser share the corrected refresh icon.

The Linux amd64 server image is `slyke/calcitequicksolve-server:v1.0.2` and
`slyke/calcitequicksolve-server:beta`. Pause mirroring and edits on the replicas
before rotating keys at the originating server.
[Server activation and peer setup](https://github.com/calcitequicksolve/CalciteQuickSolve/tree/v1.0.2/docs/hosted-server)

The Windows installer carries the CQS updater signature. The signed Android
APK supports Android 11+ on ARM64 and keeps the existing app identity.
