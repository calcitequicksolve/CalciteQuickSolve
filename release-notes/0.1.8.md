# CalciteQuickSolve 0.1.8 Beta

This beta includes the new note history and synchronization behavior.
Use 0.1.8 on every editing device and back up the complete workspace before testing.

- Notes insert literal tabs by default. Shift+Tab removes an adjacent tab;
  Ctrl+Tab and Ctrl+Shift+Tab move focus. Notes settings can disable this.
- Complete incoming changes and compatible concurrent edits merge automatically.
  Open notes update while preserving typing, selections and scroll when possible.
- Immutable, hash-verified history preserves offline branches, attachments and
  resolutions independently of the mutable note file. It uses Git-style ancestry
  without a synchronized `.git` directory.
- Conflicts have bordered excerpts, Basic/Advanced review, a count notification
  and `!` actions in History/Search. Resolve on one device and the resolution
  propagates to other devices, including after restart or unlock.
- Files & sync can review every incoming change or choose a whole local/received
  version with a notification. History-only descendants of approved content do
  not ask for another review.
- History has a refresh icon. New notes can choose a workspace before first save.
  Workspace recovery, retained-folder imports and Android deletion are improved.
- Android actions are more compact; unsupported live disk exports are hidden.
- Draft recovery, save-and-close Settings, attachment errors and compatible
  four-way histories were corrected during the audit.
- New desktop builds use this GitHub repository for update discovery/downloads.

Keep Syncthing conflict copies enabled; `maxConflicts=0` removes that recovery
layer. Ordinary content conflicts create synced conflict copies and do not stop
Syncthing. CQS validates and captures recognized copies, archives them locally,
then publishes a resolved note and history. Provider errors such as permissions,
missing folders or filename case collisions still need provider attention.

Encryption changes concurrent with edits require a protection choice under the
default Ask policy. An unlocked authorized client can retain the edit with the
chosen protection; locked clients apply that resolution after unlocking. Earlier
plaintext history/backups cannot be retroactively removed from offline devices.

Windows downloads include an installer and standalone EXE. Their Authenticode
status is unsigned; the installer has the CQS updater signature. The Android
11+ ARM64 APK retains the existing preview package ID and debug certificate and
can update the previous preview without clearing its data.

Production automatic updates are unchanged. To discover this test build in a new
desktop build, enable beta updates, or install it manually from these assets.
