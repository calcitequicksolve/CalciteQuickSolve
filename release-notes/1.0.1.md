# CalciteQuickSolve 1.0.1 Beta

This beta adds the self-hosted server, a browser UI, and encrypted server
connections for Windows and Android.

- Run the server with SQLite or PostgreSQL. Sync through the CQS API, an
  encrypted Syncthing transport folder, or both.
- Configure password or OAuth sign-in and add proxy headers to native
  connections. In each app, open **Settings → Files & sync → Server &
  encrypted sync**.
- Use the browser UI for calculations and notes. It encrypts browser storage
  and supports offline editing after setup and vault unlock.
- Sync note revisions, attachments, and calculator history. Compatible
  offline note edits merge automatically, and overlapping edits go to review.

The Windows x64 installer carries the CQS updater signature. Both Windows
executables are Authenticode unsigned. The signed Android APK supports Android
11+ on ARM64. Install it over the existing app to retain local data and keys.

The Linux amd64 server image is `slyke/calcitequicksolve-server:1.0.1`.
