# CalciteQuickSolve 1.0.1 Beta

Refreshed builds of the existing 1.0.1 beta for Windows, Android and the server.

- Display timestamps as YYYY-MM-DD HH:mm:ss in the time zone shown in General.
  Show when API credentials were generated and last used.
- Save the open server editor with Save settings, and check the saved sign-in
  when opening a server editor. Connection errors identify the redirected route.
- Open native OAuth sign-in when a gateway redirects API metadata. Default
  sign-in uses the configured issuer’s well-known OpenID Connect discovery.
- Fix the Android launch crash and align the shared refresh arrows on all three
  platforms. Place backup reference help beside its label.
- Select workspaces while adding a server connection. Approval and an explicit
  first sync still come before uploads. The connection test shows the server name,
  ID and version. General settings lets you name a client or server.
- Keep the connection editor usable during OAuth sign-in. Cancel the wait if you
  close the browser page. Protect request headers with values and keep one blank
  header row at a time.
- Put Listeners in an accordion. The API credential table reserves active names,
  allows reuse after revocation and shows the 30-day cleanup countdown.
- Show client and peer names, IDs and last-seen times. Removed directory entries
  reappear on the next authenticated request.
- Remove a workspace from this server while keeping client and peer copies. The
  next sync attempt requests approval again. Start its first sync after approval
  to restore the server copy.

Linux amd64 image: `slyke/calcitequicksolve-server:beta` or
`slyke/calcitequicksolve-server:v1.0.1`. Both tags point to the same build.

The Windows installer carries the CQS updater signature. The Android 11+
ARM64 APK retains the existing app ID, certificate and internal build code for
in-place installation. Use these downloads to replace an existing beta build.
